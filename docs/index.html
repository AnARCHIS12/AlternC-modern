Documentation AlternC

Plateforme d'hébergement mutualisé autogérée et émancipatrice, propulsée par PHP 8.3 et conteneurisée sans aucun conflit de ports.

Autogestion & Communs

Émancipation face aux géants de la Big Tech, logiciels libres copyleft et gestion horizontale des infrastructures.

Docker PHP 8.3

Conteneurisation moderne sous PHP 8.3, MariaDB 10.11 LTS et persistance stricte des volumes de données.

Zéro Conflit de Port

Ports HTTP (8080), SSL (8443) et DB (3307) isolés. Ne monopolise ni ne bloque aucun service hôte existant.

Navigation & Spotlight

Palette de commande (Ctrl+K), thème sombre/clair sobre et synchronisation interactive fluide.

Éthique Anticapitaliste & Communs Numériques

AlternC s'ancre dans une volonté d'émancipation collective, d'autogestion et de refus catégorique des logiques marchandes prédatrices du capitalisme de surveillance.

Refus de la Big Tech & Enclosures Marchandes

Rejet des monopoles propriétaires (AWS, Google Cloud, Microsoft Azure) qui privatisent le web et marchandisent les données des utilisatrices et utilisateurs. AlternC permet à tout collectif ou individu de s'émanciper totalement des silos marchands.

Autogestion & Réappropriation Populaire

Horizontalité, gestion collective des ressources et maîtrise technique directe des serveurs, boîtes mail et domaines sans intermédiaires commerciaux ni tutelle corporatiste.

Défense Inconditionnelle des Communs

Code source 100% libre sous licence copyleft, formats ouverts, protocoles interopérables et refus absolu de toute télémétrie ou dépendance fermée.

Frugalité & Sobriété Émancipatrice

Architecture légère, zéro CDN externe, zéro pistage publicitaire, fonctionnement hors-ligne (offline-first) respectueux des machines et de l'environnement.

Installation Docker en 1 commande

Un script d'installation moderne en ligne de commande configure l'environnement, inspecte les ports libres sur la machine hôte et déploie les conteneurs.

bash — Déploiement guidé 
chmod +x install.sh
./install.sh
Déploiement non-interactif (Automated / CI/CD)

Pour un déploiement direct sans interaction : ./install.sh -y.

Isolation des Ports

L'architecture Docker sépare chaque port via le fichier .env afin de cohabiter avec tout autre serveur :

Service Port Hôte par défaut Port Conteneur Variable d'environnement
Web HTTP 8080 80 ALTERNC_HTTP_PORT
Web HTTPS (SSL) 8443 443 ALTERNC_HTTPS_PORT
MariaDB / MySQL 3307 3306 ALTERNC_MYSQL_PORT

Intégration Reverse Proxy (Nginx)

Pour exposer AlternC sur un sous-domaine public (ex: panel.mondomaine.com) via un reverse proxy Nginx :

nginx.conf — VirtualHost Reverse Proxy 
server {
    listen 80;
    server_name panel.example.com;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

Référence des Variables .env

Variable Défaut Description
ALTERNC_HTTP_PORT 8080 Port web HTTP exposé sur la machine hôte.
ALTERNC_HTTPS_PORT 8443 Port web SSL exposé sur la machine hôte.
ALTERNC_MYSQL_PORT 3307 Port MariaDB accessible depuis l'extérieur.
ALTERNC_ADMIN_USER admin Identifiant de connexion administrateur au panel.
ALTERNC_ADMIN_PASS généré Mot de passe de l'administrateur principal.
DB_NAME alternc Nom de la base de données interne.

FAQ & Commandes Utiles

Comment consulter les logs en temps réel ?

Exécutez : docker compose logs -f.

Comment changer le port sans réinstaller ?

Modifiez ALTERNC_HTTP_PORT dans votre fichier .env, puis lancez : docker compose up -d.
